# 后续开发顺序

|---|---|---|
| 1 | B 站内容读取 | 五工具只读桥接、链接详情/字幕总结、无字幕短视频六帧视觉读取已实现并通过真实接口/模型验收；ASR、缓存和自主浏览仍待扩展 |
| 2 | 通用 web search / 网页阅读 | 已实现独立会话工具、官方 Search/Fetch、正文分页、来源审计与全局请求预算；真实 API/模型隔离验收及群端回复与来源确认通过 |
| 2a | 对话反馈与习惯记忆（按博士新指令提前） | 已实现六类受限偏好、个人/本群/全局作用域、来源版本、每轮加载与修订撤销；真实模型重启及自主查证、非空备份恢复、真实 QQ 群端验收通过 |
| 2b | 自动称呼学习与语义注意力 | 已实现有证据的群别名学习、本地匹配、离线 CPU/CUDA embedding 辅助召回与冷却例外；补齐判定器的自身回复和有效习惯上下文，隔离真实模型验收通过 |
| 3 | 自主发起话题和延后跟进 | 已有入站 attention 自主决定是否加入；无入站的主动调度、静默时段与独立预算待开发 |

| 5 | 记忆增强 | 已有词法检索、证据与修订、精确去重；语义召回、语义去重/冲突处理和记忆老化待开发 |

| 7 | Qt6 管理界面、记忆可视化 | 终端桌面启动器已交付；图形管理待开发 |
| 8 | 稳定性与树莓派部署 | 已有服务保活/WS 重连/缓存登录/密码回退；QQ 验证码仍需人工，ARM 实机与长期稳定性未验收 |

每项分别验证本地实现、部署状态、真实外部接口和接收端可见性。前一项的可选扩展不冒充已经交付，也不阻塞后续已明确的开发方向。
