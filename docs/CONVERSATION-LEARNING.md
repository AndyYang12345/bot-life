# 群聊语言习惯自动学习

## 交付范围

本轮把固定 persona 的措辞/性格约束改为可选的动态群语言习惯。启用时静态部分只保留机器人名字与真实身份；原有“傲娇、默认一句最多两句、强制某种口吻”等不再加载。权限、工具、来源真实性等边界独立保留。

这是**从聊天提取、更新并在推理时读取语言记忆**，没有微调 DeepSeek 权重，也不保证立刻表现得像真人。自然度、接话是否得体与是否滥用梗，需要在实际群聊中持续观察。首次样本不足会普通、简短地回应，不预置热梗词典。

## 如何学习

1. 从账本取同群近 7 天、已处理完毕的最近 60 条记录，筛出真人自己键入的顶层短文本，最终最多 16 条。引用/附件旁的真人评论可以学习，但不展开引用、合并转发、卡片或媒体里的文本；自身消息、指令、命令、明显敏感资料和明确拒绝学习的当条文字被过滤。
2. 在既有后台 consolidation 的同一个模型请求中增加小份 style 样本，最多约 3400 字符，并服从总输入预算。speaker 使用临时编号，不按昵称认人；个人事实仍只从原本 events 提取，风格来源不得混进本人记忆。
3. 模型提出最多两条表达/义项：原话短表达、function、含义、适用语境、不适用语境、置信度与原文证据。不会凭模型知道某个流行梗就说是群里学的，也不会把聊天内容变成可执行系统规则。
4. 至少 3 条不同消息、2 位说话者、置信度 ≥0.75 才启用；一人复读保持候选。证据按 event_id 去重，重复整理不能堆高票数。已启用义项不能被一条新用例改写；更新含义需一组新的多方证据。
5. 28 天内的支持不足不会继续注入，14 天没再出现的表达淡出。短句长度、emoji 频率另作群内统计，样本 ≥8 条且 ≥2 人才参考，不把统计当成硬性句数限制。

不同群各自积累。风格是表达用法，不是发言人的个人档案，也不改变同一人的跨群事实记忆。后台没有读取尚未入库的 QQ 历史。

## 如何使用

每轮加载本群少量 active 用法及近期真人消息；判断要不要接话时也能参考其语义。表达只在语境合适时试用，每轮至多一个；最近四块已确认发送中用过的表达先过滤。严重/不合适情景、明确停用表达和当前用户意图优先。没有合适的梗就普通说话。

默认仍追求简短凝练，复杂问题按需展开，不机械固定一句/两句，也不强制傲娇、旁白或固定口头禅。模仿不会开放 shell、任意文件、跨群查询或其他 MCP 权限。

`/new` 清短期会话，语言习惯继续保存在数据库。学习暂停会停止新的语言提取与注入，已有个人记忆可继续工作；长期不使用的规则不会通过重复处理旧样本刷新年龄。

## 数据与管理

schema 6 新增：

| 表 | 内容 |
|---|---|
| life_style_profiles | 本群短句/emoji 统计、样本来源及版本 |
| life_style_rules | 候选/启用/停用的短表达、义项、语境、置信度、最后出现时间 |
| life_style_evidence | 原始 event_id、短表达证据、说话者标识；说话者只用于验证多方支持 |
| life_style_revisions | 不可变版本快照 |

模型只有这些数据的有界上下文，没有直接修改自身 system prompt/代码的工具。应用角色不能删除规则或编辑历史；所有更新走有租约、作用域和暂停检查的后台。管理端可：

```sh
scripts/life-admin style-list --conversation onebot:ACCOUNT:group:GROUP
scripts/life-admin style-suppress --conversation onebot:ACCOUNT:group:GROUP --style-id RULE_UUID
scripts/life-admin style-reset --conversation onebot:ACCOUNT:group:GROUP
scripts/life-admin style-pause
scripts/life-admin style-resume
```

reset 清本群语言库并设置学习水位，旧原文不会立即重建相同规则；不删除个人事实记忆。suppress 停用该表达，并失效旧短期 session。普通 export/delete 已包含风格及其来源/版本；物理删群时不会留下对应语言库。逻辑个人遗忘不等于删除所有群语言习惯，历史审计/备份也不会被自动抹除。

首次启用可运行 `style-bootstrap --conversation ...`：只创建一个有界语言快照任务、不重放个人事实、不回退原有游标、不伪造群友消息、不发 QQ 消息；同一学习水位只请求一次。仍遵守现有后台预算。

## 运行与预算

私有 `adapter.json` 新增：

```json
{"conversationLearning":{"enabled":true,"identityName":"奶鲸"}}
```

缺省关闭以兼容旧部署。依赖 schema 6 和既有 memory consolidation 服务；沿用独立密钥及每小时 2 次、滚动 24 小时 12 次的全局后台预算，不为每条消息新开学习调用。联合学习会增加少量输入/输出 token，用量仍归入 memory_consolidation；聊天/attention 单独统计。启动快照可能因预算用尽排队，不能绕过额度。

启用不要求反复发“记住”或专门教规则，日常聊天即可。当前没有在线点赞奖励/权重训练、自动判断群友内心反应或持续搜索互联网热梗；只是可审计的语言用法归纳与上下文适配。

## 验证

`scripts/check-project` 覆盖真实 PostgreSQL 中的候选晋升、跨群/来源隔离、短句统计、重复抑制、老化、停用/暂停/重置、导出删除、不可变历史、共享后台预算与 bootstrap 幂等。

本机加载独立 model.env 后可执行：

```sh
node scripts/verify-shared-runtime.mjs --style-learning
```

2026-10-21 隔离真实模型验收：从多人使用的临时表达生成 1 条 active 语言规则，4 条真实样本证据；没有预置该用语。真实 DSH 在恰当场景输出 20 字回复，在测试失败场景避开该庆祝说法；旧 persona 固定口癖未出现，短期 reset 后仍可使用。非空 schema 6 的语言库备份恢复成功。测试连接的是本机模拟 OneBot，没有向真实 QQ 发消息，临时样本也没有写入正式库。

这些结果证明机制与链路可用，真实群的自然度、文化贴合度和长期老化仍待持续观察。正式启用后可能暂时没有足够证据形成 active 用法，应如实查看 style-list，不把候选说成已经掌握的群习惯。
