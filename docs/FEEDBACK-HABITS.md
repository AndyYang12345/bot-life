# 对话反馈与习惯记忆

2026-10-21，接在网页工具之后实现，用于把明确教导变成持久、可查看、修订和撤销的行为偏好。它独立于普通事实记忆和群语言用法，不依赖检索碰巧命中，也不是修改模型权重。

## 从自然对话生效

每条允许会话的消息先取当前真人自己键入的文字，识别支持的明确反馈，实际写库后将 observation 和有效习惯交给当前回合。反馈和管理请求会进入正常回复流程，不被普通接话冷却直接忽略；只有实际保存成功才可确认。没有额外的习惯提取模型请求，不在后台偷偷批量转换旧聊天。

例如：

> 以后对我的回复简短一点，不要分点，直接给答案，不用播报搜索过程。

> 以后遇到版本等不确定的信息主动上网查证，优先官方来源，把结果融入回答。

> 改为详细回答。

> 查看你记住了哪些习惯。

> 撤销“不分点”那条回复形式习惯，其他保留。

默认是当前发言人的个人习惯，同一 QQ 账号在多个已授权群共享，昵称不参与身份判断。明确说“本群/这个群”才是本群习惯，明确说“所有群/全局习惯”才是当前机器人账号的全局习惯；后两种只允许 ownerIds 中的管理员修改。不能指定其他人、其他群或把全局默默降为个人保存。

每轮从数据库主动加载，优先级为当前明确任务要求 > 个人 > 本群 > 本机器人账号全局 > 默认语言风格。个人习惯不会强迫同群其他人使用；各群仍有独立的口头禅和语言统计。跨群上下文不暴露原群名称、QQ 群号或原文。撤销后回到下一层已启用习惯/默认行为，不继续执行被撤销记录。

## 首版可保存的习惯

| setting | 可选行为 |
|---|---|
| reply.length | 简短、适中、详细 |
| reply.format | 自然聊天、按需分点 |
| reply.tone | 日常、中性、正式 |
| reply.process | 先给答案并自然融合查证结果、简短说明方法或依据 |
| search.mode | 遇到时效/待核实事实主动查证、仅在明确要求时联网 |
| search.sources | 优先官方/一手来源、多方交叉核对 |

这是受限的行为选项，不是任意文字都能变成系统规则。没有认识到的表达、其他习惯或严格句数等要求，不能声称已经永久掌握。原文含身份/权限越界、密钥、链接或明显个人资料时不自动保存；转发、引用、网页和给其他人的 @ 消息不能成为教导证据。“仅这次/不用长期记住”也不自动固化。

首版不是完整情绪理解、任意反馈奖励学习、人格分析、自主目标或自我改写。复杂触发条件和新的习惯类型以后扩展；原有后台群语言学习继续归纳用语和场景，不会把群员的普通发言直接变成全局规则。

## 保存、应用与管理

schema 8 新增 life_habits、life_habit_revisions、life_habit_ops，分别保存当前作用域/选项/版本/状态、不可变原文证据及版本快照、同一回合操作去重结果。修改要求 expected_revision，避免旧版本覆盖；只有当前入站真人原文可以授权保存/撤销。习惯改变会失效相关短期会话，保留事实记忆与其学习水位。/new、重启服务和 QQ 重连不删除习惯。

DSH 本轮注册 habit_list / habit_save / habit_revoke；模型不能传 actor、管理员名单、账号 realm、其他群或任意自由行为。个人、本群、全局的归属与权限由服务检查。写入每轮至多 6 次工具调用；明确反馈的自动识别不另加模型请求。反复确认同一值不堆高版本，重试不重复写入。

“仅在明确要求时联网”有实际网页工具检查，不能只靠模型口头承诺；用户本条明确不联网也会阻止网页调用。主动查证仍由模型判断是否需要，受网页请求预算约束，不能保证永远正确识别不确定性。表达风格属于推理时偏好，不能数学保证每次完全符合。

配置模板中 habits.enabled 默认 false，本机启用后重启适配器。管理端可：

```sh
scripts/life-admin habit-list --conversation onebot:ACCOUNT:group:GROUP
scripts/life-admin habit-pause
scripts/life-admin habit-resume
```

暂停只阻止新写入，已有有效习惯仍可应用。自然对话可以查看、修改、撤销；source/revision 历史也包含在 export。物理删除来源群时移除所有依赖该群证据的习惯，包括后来在别群修订的共享习惯，并失效受影响会话；不可变历史不是永久删除的例外。数据库备份包含这些表，媒体与 DSH 文件仍需单独备份。

## 验证与交付边界

回归覆盖真实 PostgreSQL 中的自动保存/去重、同账号跨群和其他人隔离、owner 权限、作用域优先级、旧版本冲突、修改/撤销、pause/租约、引用与越权过滤、导出删除和不可变审计；适配器覆盖工具绑定、调用限额、错误隐藏、模板字面量和联网习惯门控。

本次项目检查合计 249 项通过：life-core 138、适配器 90、桌面启动器 13、B 站后端 8；包括实际 worker 进程在最新 schema 上启动且不调用模型的回归。TypeScript 检查与构建通过。

真实 DSH/模型 + 独立 PostgreSQL + 模拟 OneBot 验收通过：

- 普通话反馈保存三条个人习惯，不依赖模型声称“记住”。
- 实际停止并重启 DSH 后，重新加载习惯，按简短、自然聊天的偏好回答。
- 模型实际调用撤销工具，取消形式习惯并保留其他两条。
- 教导“遇版本等不确定信息主动查证”后再次重启，用户只问最新版本，模型自行调用网页搜索并给出来源。
- 改为“仅明确要求时搜索”后，普通时效问题没有发出网页请求。
- 非空习惯库备份恢复，重施运行角色权限后读取有效，包含 5 条习惯与 7 个版本。

隔离验收不向真实 QQ 发消息；证据保存于忽略的 evidence/habit-runtime.json。生产启用、迁移前后数据计数和真实群端测试另外记录，不把模拟回执当作实际可见性。

正式库已迁移 schema 7 → 8，事实记忆 3 条、记忆修订 5 条、人物 7 个、群语言规则 2 条迁移前后计数一致。已有三个允许群启用习惯功能；QQ 持续在线，适配器和后台整理 worker 已恢复。迁移发现并补齐了后台 worker 对 schema 8 的启动检查，并新增实际进程启动回归，禁用模型的检查不额外调用 API。迁移前、迁移后 PostgreSQL 备份均在独立库恢复验证通过；证据在 evidence/habits-production-migration.json、habits-*-migration-backup.json 与 habits-worker-schema-acceptance.json。

真实 QQ 群端验收也已通过：博士确认已保存习惯、回复简短且会主动查证。后台对应 5 条个人习惯（简短、自然聊天、先给答案、主动查证、优先官方来源）；下一条没有明确要求搜索的问题加载这 5 条习惯，实际完成 2 次 web_search 和 1 次 web_fetch，最终回复 99 个字符、无分点且含来源链接，全部消息分段确认送达。仅保留事件关联、设置与统计的证据在忽略的 evidence/habits-production-acceptance.json，不将真实聊天或身份写入仓库。
