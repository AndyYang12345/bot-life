This independent read-only bridge follows the integration ideas reviewed in
`docs/BILIBILI-PLUGIN-REVIEW.md`, including the use of bilibili-api-python,
FastMCP, subtitle language preference and QR authentication. Reference:
https://github.com/c1overzz/dsh-bili-scroll/tree/eab82bb749bdab1e58723b734011dbb583993785

No upstream plugin code is vendored in this directory. The account write tools,
shell/ASR pipeline and plugin installation hooks are intentionally absent.
Dependency licenses remain with their respective authors.
